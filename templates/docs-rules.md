## 문서

| 문서 | 위치 | 언제 고치나 |
|---|---|---|
| 지금 시스템(한눈에 보기, 기술 스택, 주요 흐름, 데이터 모델) | `{system}` | 이 문서가 설명하는 내용을 바꾸는 PR에서 함께 고친다 |
| 변경 기록(변경마다 하나씩 쓰는 계획 문서) | `{plans}` | 변경을 시작할 때 쓰고, 끝나면 결과를 적는다 |
| 승인된 화면 시안 | `{designs}` | 화면을 새로 만들거나 크게 바꾸기 전에 승인받은 사본을 둔다 |
| 사용 설명서 | `{manual}` | 사용 방법이 바뀌는 PR에서 함께 고친다 |

- 조사는 지금 시스템 문서에서 시작한다.
- 데이터 모델 문서의 ERD에는 DB의 모든 테이블을 넣는다.
- 위 자리 밖에 문서를 새로 만들지 않는다.
